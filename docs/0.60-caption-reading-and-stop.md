# 0.60 字幕阅读与暂停响应

短字幕仍及时显示；中文、日文、韩文按字估算阅读时间，其他文字按字符估算。字幕最少停留 0.75 秒，最长 4.5 秒。旧版长段译文最多显示 1.5 秒，容易在读完前被下一条覆盖。显示队列继续按顺序处理，积压时可手动重新同步；本次共享最近 20 条原文和译文保留。

暂停、重新同步、停止共享不再在界面线程调用原生录音 stop。停止请求在后台执行，与录音启动和释放串行，避免停止和释放同时操作同一录音对象。取消早于启动时禁止启动；多次停止或释放不会重复释放。准备后的识别器状态不合格时也会走清理。

新增回归覆盖：长中文与短字幕的阅读时长、补充平面汉字、阻塞的录音停止不阻塞调用方、停止过程中禁止释放、取消早于启动、停止抛错仍释放、重复释放与已取消对象禁止重新启动。继续执行既有 API 29/33 模拟器字幕、暂停恢复、实际模型翻译与离线重载检查。

本版未更换识别或翻译模型。阅读时长是显示策略，不代表识别准确率、翻译质量或端到端延迟的实测提升。原签名沿用 0.53–0.59，包名 com.opennomi.android，版本代码 60。用户手机及蓝牙耳机仍需实际使用验证。
