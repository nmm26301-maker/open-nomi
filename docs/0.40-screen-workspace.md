# OpenNomi 0.40 屏幕共享互动

本版本基于现有 0.39 Android 源码增量修改，保留 NOMI 原声与 AIRI 两个角色入口。未加入已取消的五角色包。

## 参考图的落地范围

| 构思 | 本版实现 | 使用条件或边界 |
|---|---|---|
| 首页 | 原有大球球、NOMI / AIRI、看屏幕 / Agent / 碎片本快捷入口 | 使用原来的账号绑定 |
| 屏幕理解 | MediaProjection 共享、离线中英文 OCR、页面控件读取、文字问答与图片问答 | 图片问答需配置视觉模型；受保护窗口可能黑屏 |
| Agent 执行 | 输入任务→规划→显示建议→确认操作→重新观察并规划下一步；暂停与任务记录 | 智能规划需要模型；控件操作需要无障碍；每一步均需确认 |
| 实时翻译 | 原文和中文的底部字幕浮条、中文跳过、排队留足阅读时间 | 可使用已连接的原声 NOMI，也可配置模型 / LibreTranslate；目标 App 能否被读取影响结果 |
| 碎片本 | 原图分享 / 图库原文件导入、页面文字记录、想法与问答保存、删除 | 双击保存页面文字，不把屏幕截取伪称原图 |
| 记忆中心 | 本机记忆列表、手动保存和删除、可选择在屏幕问答中使用最近记忆 | 默认不把记忆发送给模型；开启后发送最近 8 条 |
| 悬浮球交互 | 单击打开功能面板、双击保存文字、长按问屏幕、上滑翻译、右滑语音、下滑历史；拖动移动球球 | 需悬浮窗权限；语音输入使用手机系统识别服务 |
| 翻译浮动条 | 原文 + 译文，自动换行，阅读时间 5–14 秒，更新不立即替换未读字幕 | 以最新待显示字幕替代过时排队内容；超长视频字幕可能落后 |
| 设计系统 | 深色背景、蓝紫强调色、圆角卡片与按钮、统一页面导航 | 原生 Compose UI；不是新增 Figma 文件 |
| 动效规范 | 原有 Emotion Ball、按压与页签反馈；悬浮球呼吸与状态颜色 | 不承诺与概念图像素一致 |
| Android 13 | 显式共享授权、前台服务、停止入口、无障碍与悬浮窗权限引导 | 本次未连接用户手机或模拟器进行实测 |

## 开源接入

- Tesseract4Android 4.9.0：已实际编入 APK；随包提供中英文 tessdata_fast 识别数据。
  https://github.com/adaptech-cz/Tesseract4Android
  https://github.com/tesseract-ocr/tessdata_fast
- Vosk Android 0.3.75：已实际编入 APK；随包提供 small-en-us-0.15 英语识别模型。
  https://github.com/alphacep/vosk-api
- Open-AutoGLM：接入其 OpenAI 兼容图像请求与动作输出格式。并未把依赖 ADB 的 Python 框架或 9B 模型直接塞入手机。
  https://github.com/zai-org/Open-AutoGLM
  坐标动作仅在能映射到当前可访问控件时转换为点击，避免盲点旧位置。
- LibreTranslate：已实现 `/translate` 接口适配；服务和语言模型需要用户部署或选择已有服务。
  https://github.com/LibreTranslate/LibreTranslate
- RTranslator、UI-TARS：调研参考，本版未复制其完整 App 或内置其翻译模型。
  https://github.com/niedev/RTranslator
  https://github.com/bytedance/UI-TARS

## 使用步骤

1. 安装本次 ARM64 APK。应用 ID 与已有 0.39 一致，签名一致时可覆盖升级，无需卸载。
2. 先确认首页 NOMI 已绑定且可正常对话。
3. 打开“看屏幕”，允许“悬浮窗”，按需启用 OpenNomi 无障碍读取。
4. 点“开启屏幕共享”，确认 Android 系统授权，切换到要看的 App。
5. 点或长按球球，输入问题；双击球球保存页面文字。
6. 需要图片理解或智能规划时，在“连接”页填写视觉模型的 OpenAI 兼容地址（到 `/v1`）、模型名与可选密钥。
7. 任务每一步需确认，确认后重新观察页面。可以随时取消、暂停或停止共享。此版本采用逐步确认流程，还未实现无人确认的连续自动执行。
8. 保存原图：在图片所在 App 选择“分享 → OpenNomi”，或打开碎片本选图。保留原始图片字节。
9. 英语视频声音识别通过 Android AudioPlaybackCapture 直接读取播放音频，未捕获到声音会提示切回文字字幕。其他语音识别语言尚未内置。

## 模型与费用

未预设匿名公网模型接口，未承诺服务永久免费。视觉模型、翻译速度和质量取决于接入服务、设备和页面结构。视觉大模型与离线翻译模型并未内置在本机；NOMI 原声和默认文字翻译仍使用原来的在线服务。

## 验证范围

包含 Android release 编译、单元回归、Android lint、AIRI JavaScript 回归、APK 签名与对齐检查、旧版签名和安装包 ID 比对。测试覆盖字幕阅读等待、模型动作解析与越界拒绝、共享撤销后旧结果拒绝，以及原有对话协议。

真机首次授权、OEM 后台限制、视频 App 录音许可、原有在线账号响应和外部模型端到端连通仍待用户设备测试。构建通过不能代替真机运行验证。
