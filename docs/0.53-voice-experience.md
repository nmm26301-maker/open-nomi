# OpenNomi 0.53.0 语音体验

## 更新

- 空白语音识别事件不再切换聆听/思考状态，也不会触发打断。
- 在同一回答的思考或播放期间，忽略与当前问题相同的重复最终识别结果；进入下一次聆听或明确开口打断后，仍可重复同一句问题。不同文字的识别事件保持原处理方式。
- NOMI 设置新增“说完等待”：敏捷 480ms、自然 700ms、从容 1200ms。经常在句中被抢话时可选从容。此值控制本机单向对话的结束检测；双向对话仍由语音服务判断结束时机，不保证改变服务端等待。
- 原“快速回复”改为“快速分句播放”，只控制 FishAudio 较长文字在逗号处提前合成。首次未选择停顿档位时兼容旧的 480/700ms 偏好；选择档位后独立保存。更改任一选项会暂停当前对话，点球球重新开始。
- 麦克风编码器初始化失败也会释放录音和音效资源，避免异常路径占用麦克风。实际启用回声消除后才使用双向打断的检测参数。

## 安装

0.53.0 使用已备份的新签名和独立包名 `com.opennomi.android`。旧版 `com.opennomi.android.voicetest` 保留，两版数据隔离。新安装需重新绑定和配置，旧记忆不自动转移。之后新版沿用此包名和同一新签名，支持其自身覆盖升级。

原 0.52.0 APK 的原签名私钥仍未找回，新签名无法覆盖原版。加密签名备份在 `Zizai` 私有仓库的 `backup/opennomi-0.52.0-20261012` 分支（`backups/OpenNomi-0.52.0/new-signing-20261012/`），恢复钥匙另存，不提交 GitHub。

## 验证与体验

新增回归覆盖空白/重复识别、下一轮重复问题、旧设置回退、1200ms 句中停顿、短噪声与持续开口，以及 Android 下实际 ViewModel 的识别处理和停顿设置重载。检查完成结果记录在发布校验文件中；未运行的项目不视为通过。

建议在手机上先用“自然”，说一句包含停顿的话；若提前回应，改为“从容”。开启允许打断后，在回答中途开口；手机须实际启用硬件回声消除，耳机须支持通话麦克风。服务端识别、合成延迟、蓝牙拾音及小米后台行为需真机验证，本版不承诺固定提速比例。
