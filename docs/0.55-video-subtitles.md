# OpenNomi 0.55.0：无字幕视频声音翻译

在工作台的翻译页选择视频原声语言，点“开启无字幕视频字幕”，允许音频录制、屏幕共享和悬浮窗。模型就绪后切到播放器，再播放无字幕视频。中文字幕显示在底部，同时可显示识别原文和标注“识别中”的临时原文。

声音从 Android AudioPlaybackCapture 接收，不依赖视频自带字幕或 OCR。英语轻量模型内置；英语增强模型约 128 MB，日语约 48 MB、韩语约 82 MB、法语约 41 MB、德语约 45 MB、俄语约 45 MB、西班牙语约 39 MB，首次从 Vosk 官方 HTTPS 来源按需下载。语音模型和翻译模型提前准备后可离线使用。默认只在 Wi-Fi 下下载，也可允许移动网络。

完整识别语句按到达顺序翻译，不再覆盖翻译请求期间到达的语句。长时间不停顿的讲话会分段结束识别；临时原文只用于预览，不把它当成最终译文。视频模式不再经过 OCR 字幕 2.5–10 秒的阅读等待。停止、切换或取消准备会使旧回调失效。翻译队列上限 12 句，过载会明确提示，不能保证高速或长时间网络故障时不漏字幕。

手机翻译继续使用 ML Kit，无需 API Key。可在连接页配置自己的在线文本模型或 LibreTranslate；在线模型收到最近原文作为指代上下文，只翻译当前句，要求保留人名、数字、否定关系。LibreTranslate 收到所选原声语言，避免把日语汉字按中文跳过。在线服务的费用与运行条件由其提供方决定。

小语音模型对口音、背景音乐、重叠讲话和专有名词仍可能识别错误，低置信度语句会提醒核对原文。英语增强模型是可选模型，不能据其名称承诺每个视频都更准确。翻译并非零延迟；真实手机和视频内容的速度、准确率需实测。

Android 10 以上支持捕获播放声音，但播放器必须允许系统音频捕获；系统不允许的声音或受保护媒体不能绕过。相同设备的耳机输出使用同一播放声音通道，但本版测试不等于真实蓝牙耳机验收。

模型来源与 Apache-2.0 许可证：[Vosk models](https://alphacephei.com/vosk/models)。系统捕获条件：[Android audio playback capture](https://developer.android.com/media/platform/av-capture)。手机翻译来源：[ML Kit](https://developers.google.com/ml-kit/language/translation/android)。

本版使用版本代码 55、包名 `com.opennomi.android`，沿用 0.53/0.54 发布证书。发布时归档签名 APK、同一套签名和密码的加密副本、源码提交和实际验证结果，并从 GitHub 回读恢复安装包进行 SHA-256 校验。
