# OpenNomi 0.59.0：视频字幕暂停恢复与常用操作

修复暂停视频字幕后隐式切到画面文字翻译的行为。暂停时停止声音识别、取消本次翻译并清空未完成语句和待显示字幕，翻译开关同时关闭；不会自动把视频画面里的文字送去翻译。保留本次共享的已完成近期译文，屏幕共享仍开启，画面问答与用户主动启用画面文字翻译的能力保持可用。停止共享才清空本次近期译文。捕获中断或模型准备失败也停止翻译并保留原因，避免失败后转入未请求的文字翻译。

“近期译文”页增加“继续视频字幕”。继续使用已经授权的共享、已安装的模型和所选原声语言，不重复请求屏幕共享许可。识别器仍需重新加载，不能承诺零等待；恢复后只接收当前捕获结果，旧任务和旧录音的晚回调不能重启或覆盖暂停状态。

视频字幕页将开启／暂停、同步、回看与实际译文移到模型设置之前，运行时默认收起语言与模型设置，仍可主动展开。原文显示开关保留在常用区域。本机译文显示 Google 翻译来源；缓存、分段、字幕顺序及近期列表规则沿用 0.57–0.58。

版本代码 59，包名 `com.opennomi.android`，沿用 0.53–0.58 证书。检查包括暂停时不触发画面文字翻译、保留共享会话和近期译文、清空待处理状态、故障原因保留；Android 10／13 实际独立播放器无字幕声音捕获、悬浮入口、同步、暂停回看及同一共享会话恢复后的中文字幕。仍包含模型下载、无网络重载与翻译、旧回调隔离及画面资源关闭顺序验证。不作未经实测的手机准确率、固定延迟或蓝牙表现保证。
