# OpenNomi 0.56.0：视频字幕速度与开启流程

翻译页优先显示无字幕视频入口。选择原声语言，点“开启无字幕视频字幕”；若缺少悬浮窗权限，会先打开系统设置，授权返回后继续申请声音和共享权限。没有悬浮窗权限时不会悄悄开始声音捕获。首次使用需准备识别和翻译模型，默认只在 Wi-Fi 下载。提前准备的进度和取消按钮显示在视频卡片内。

新增两种分段方式：默认“更快显示”在连续讲话时约 3.5 秒分段，Vosk 原生停顿检测使用 0.45 秒基础停顿参数；“完整语句”保留原来的约 5.5 秒分段上限，基础停顿参数为 0.8 秒。实际原生终点还受解码置信度和模型规则影响，这些参数并非端到端字幕延迟保证。更快分段可能拆开长句，长句、术语较多的视频可以选完整语句或英语增强模型。

翻译结束后马上尝试下一条，不再等下一个 250 ms 轮询周期。队列达到 4 句时，可将最多 3 条已经等待的相邻原文合为一次请求，保持顺序和重复内容；不等待凑批、不丢掉已接收的句子。组合上限约 360 字符，长句单独处理。失败时重试同一批原文，成功后才删除对应条目；停止后旧结果不能删除新会话的内容。组合字幕继承其中最低识别置信度，提醒核对原文。队列仍最多 12 句，持续过载会明确提示，不能保证网络长期故障时不漏字幕。

视频声音模式下，不再把手机翻译的每次内部状态刷到字幕上；音频译文不使用画面文字的缓存，在线模型可据当前前文重新翻译同一句。没有屏幕问答或任务时，视频模式的画面采集间隔从 900 ms 调整为 2400 ms，减少画面识别工作；屏幕问答、Agent 和画面文字翻译仍使用 900 ms 间隔。配置轮询只比较加密后的配置值，避免每轮为变化检测调用系统密钥解密。

包名仍为 `com.opennomi.android`，版本代码 56，沿用 0.53–0.55 发布证书。测试覆盖快／完整两种模式的实际播放器声音捕获、中文字幕与停止取消，以及日语模型下载、离线加载和翻译。模拟器测试不等于真实手机或蓝牙耳机验收，也没有给出准确率提升百分比。播放器仍须允许 Android 系统声音捕获；受保护媒体无法绕过。

模型来源：[Vosk 官方](https://alphacephei.com/vosk/models)；原生分段规则：[Vosk Recognizer](https://github.com/alphacep/vosk-api/blob/master/src/recognizer.cc)。基本用法与首次下载说明见 [0.55 文档](0.55-video-subtitles.md)。每次发布归档安装包、原始报告和签名／密码加密副本，并从 GitHub 回读恢复核验。
