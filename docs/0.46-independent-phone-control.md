# 0.46：手机操作跳过小智播报

默认开启“语音控制优先”：明确操作走本机执行，其他语音直接作为目标交给手机任务模型，不必先说“执行任务”。设置中关闭该项可恢复普通小智聊天。控制模式会丢弃普通聊天的迟到文本、TTS 状态和音频，避免重新占用收音；明确的翻译文本请求保持独立。手机控制和聊天回应分开。控制指令完成、失败、取消、暂停、需要确认或选择应用时，只更新球球状态和任务记录，马上恢复收音；不会向小智提交“朗读操作结果”，不会启动系统中文朗读，也不会等待 TTS。语音转文字仍使用已连接的小智语音服务，需要联网。执行线路独立不等于离线识别。

前台语音服务保留用户明确开启的会话，系统重建服务时可以恢复连接；用户暂停会取消恢复。小米系统的省电或强制停止仍由系统控制。

执行期间后续明确指令进入最多十二条的队列；取消会清空未执行的后续指令。长任务仍可说暂停任务、继续任务或取消任务。开启回声消除的手机在共享屏幕时也保留双向语音能力，不再因为屏幕共享关闭该能力。

手电筒通过 CameraManager 的长期状态回调验证真实状态，连续打开、关闭和重复关闭共用观察器；相机已打开时使用 CameraX 的 cameraControl，避免摄像头被占用造成手电筒失败。失败不会宣称成功。

新增 OpenNomi 语音相机（不是小米系统相机）：打开相机 → 拍照 → 退出相机。支持自拍和切换摄像头。CameraX 真实调用 ImageCapture.takePicture，收到保存成功回调才报告照片已保存。Android 10+ 保存到相册 Pictures/OpenNomi，无需读取全部照片。Android 8/9 保存到应用照片文件夹。退出会释放摄像头。用户可以语音打开其他已安装的相机 App，但该 App 的拍摄按钮能否控制取决于无障碍控件；这里的“拍照”固定使用内置语音相机。

自然任务如“打开微信搜索张三”会进入已有的逐步观察、规划、执行线路，不再误把“微信搜索张三”当成应用名；需要配置可用视觉模型、开启无障碍和屏幕共享。简单硬件指令及内置拍照不依赖视觉模型。点击、点赞、打字依赖目标页面可访问的控件；不保证任何 App 的所有操作。发送、发布、支付、删除仍需单独确认。首次麦克风、相机、无障碍、悬浮窗及共享授权由 Android 系统管理。

工作台“手机权限”新增同时申请麦克风和相机并开启语音的入口，避免只有麦克风权限却尝试操作手电筒。可说“语音诊断”查看授权情况和控制状态。

## 验证

新增生产队列与状态观察器的回归：分两句话打开/关掉手电筒、重复关闭、延迟初始回调不能提前确认、硬件不可用后恢复、保存完成前收到退出相机的后续指令、取消清队列、相机多步解析及疑问/否定语句不触发操作。构建、单元测试和 lint 的最终结果随交付说明记录。未连接用户的真实手机，不能把模拟回调通过当成小米实机测试。

## FishAudio 输出

首页设置新增 FishAudio 配置与实际试听。使用官方 POST /v1/tts，JSON 请求，Bearer API Key 和 model 请求头；音色由 reference_id 指定，可留空使用服务默认音色。默认模型 s2.1-pro-free，是否可用及额度由账户决定。可切换账户支持的模型或 HTTPS 兼容服务地址。密钥由 AndroidKeyStore AES-GCM 加密存储，不写入源码或日志。

配置启用后，小智提供回答文字，FishAudio 合成 MP3，Android MediaPlayer 播放。不会先播小智原音，也不会等待原音失败后重试；不强制切换系统中文朗读。按标点分段处理长文字并保留 emoji，等待真实播放完成才恢复收音。取消会取消 HTTP 和播放，清理临时 MP3，防止迟到播放。FishAudio 播报期间暂停收音，可点球球暂停；当前尚不提供 FishAudio 播报时的语音打断。播放失败保留回答文字并显示具体原因，恢复持续聆听。手机控制仍走静音执行线路。

本次是语音合成 API 接入，不在手机部署 Fish Speech 模型权重，不替换小智的语音识别或手机视觉任务模型。配置官方服务需要用户自己的 API Key 与网络，没有真实密钥不能验证账户授权或云端音色。未复制第三方实现；接口依据官方文档并核对 FishAudio 官方 Python SDK（Apache-2.0）。

- 官方 TTS 接口：https://docs.fish.audio/api-reference/endpoint/openapi-v1/text-to-speech
- 官方 SDK：https://github.com/fishaudio/fish-audio-python
- API Key：https://fish.audio/app/api-keys

新增 HTTP 回归覆盖 JSON 参数、模型请求头、音色 ID、二进制不变、默认音色、账户与额度错误、取消请求、重定向隔离、空/文本/过大响应，以及中文 emoji 长回复的无损分段。测试使用 MockWebServer，不代表用户账户的云端调用或真实手机播放已经成功。
