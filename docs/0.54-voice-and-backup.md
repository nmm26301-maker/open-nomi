# OpenNomi 0.54.0

## 语音

连接尚未完成时点“取消开始说话”，同时撤销自动续聊意图和已排队的恢复任务。随后握手完成或连接断开，都不会因为这次已取消的请求自动开启麦克风；用户再次点开始仍可以正常说话。

FishAudio 快速分句播放遇到至少 18 个字符的完整逗号短句后，立即将它送入合成队列，不再等总文字达到 36 字符。短句与无标点文本仍保持原来的等待与分段限制。数字末尾的英文逗号在尚未收到后一个字符时暂缓判断，避免流式发送 `1,` 和 `000` 时误拆数值。总体验仍受语音服务和网络影响，不承诺固定提速比例。

## 翻译修复

默认启用 ML Kit 手机翻译通道，无需视觉模型密钥或 LibreTranslate 地址。语言识别模型随安装包提供，翻译语言模型首次按需下载；默认只允许 Wi-Fi，用户可在翻译页允许移动网络。翻译页新增直接输入原文、源语言选择、准备模型、试译、取消及实际状态显示。译文由 Google 翻译，输入和译文在本机处理；SDK 会联网获取模型、更新与发送运行统计。它是 Google SDK，不称为开源模型；LibreTranslate 开源接口继续可选。

实时浮条不再因缺少视觉模型配置而拦住手机翻译；首次模型准备状态显示在浮条。日语假名不再因为汉字占比高而被当作中文丢弃。视频声音仍用内置 Vosk 英语识别，播放应用可能禁止捕获；翻译功能无法绕过系统限制。当前 OCR 内置中英文，日语画面可通过无障碍文字或手动输入。

SDK 与来源：[ML Kit 翻译](https://developers.google.com/ml-kit/language/translation/android)、[内置语言识别](https://developers.google.com/ml-kit/language/identification/android)、[隐私说明](https://developers.google.com/ml-kit/terms)。

## 安装与备份

包名 `com.opennomi.android`，版本代码 54，固定沿用 0.53.0 新签名。可覆盖升级 0.53.0 并保留其本机数据。与原签名旧包名 `com.opennomi.android.voicetest` 并行存在，旧版数据不自动迁移。

每次生成的已签名安装包在本仓库 `backups/releases/<版本>/` 按分片归档，使用该目录的 `restore.py` 自动合并，校验所有分片及完整 APK 的 SHA-256，默认拒绝覆盖已有输出。发布校验记录包含实际源码提交、构建、测试计数和签名证书摘要。

本仓库 `backups/signing/new-signing-20261012/` 加密保存 JKS 私钥、别名、密钥库密码和密钥密码，并提供恢复脚本。加密副本本身可公开；解密钥匙单独保存，不放进仓库，也不写进日志。每版 `backups/releases/<版本>/signing/` 保存本版使用的同一签名加密副本、恢复脚本及校验摘要，避免后续换钥匙导致覆盖安装失败。旧签名私钥仍未找回，不将新签名描述为旧签名。

恢复签名需 Python 3 和 cryptography：

```sh
python3 backups/signing/new-signing-20261012/decrypt.py --key-file /path/to/OpenNomi-new-signing-recovery-key.json --output-dir restored-signing
```

测试结果由实际完成的构建与发布验证记录填写；模拟器与测试服务不能代替真实耳机、用户账号和手机后台验证。
