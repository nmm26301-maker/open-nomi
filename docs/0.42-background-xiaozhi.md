# OpenNomi 0.42：后台小智语音与屏幕陪伴

这版把悬浮球的语音入口接到原有小智语音会话。麦克风由常驻前台服务持有，切到其他 App 后继续聊天，回答走小智的原声语音合成与 Opus 播放，不使用系统语音转文字弹窗。

## 手机上怎么用

1. 直接覆盖安装，保留原来的小智绑定。
2. 首页连接小智；若显示验证码，到 https://xiaozhi.me/console/ 绑定设备，绑定后重新连接。
3. “看屏幕”→开启屏幕共享；允许悬浮窗。
4. 球球长按或右滑，或点球球→“小智语音聊天”，允许麦克风。切回要看的 App 后直接开口。
5. 可以问：“小智，你看看我在干嘛”“这张图片是什么”“这页下一步点哪里”。小智会回答并接着听下一句。
6. 点语音入口或通知中的“暂停语音”关闭麦克风；停止共享同时停止相关语音会话。

普通聊天直接走小智语音服务，屏幕问题才追加屏幕资料。未接视觉模型时只能用当前屏幕文字；连接页配置视觉模型并通过看图测试后，屏幕问题会先理解最新画面，再交给小智口语回答。这个模式采用说完一句再回答，尚未实现看屏幕时随时打断。

## 翻译改进

- 屏幕采样最低间隔由 2.4 秒改为 0.85 秒；实际 OCR 用时和网络仍会影响速度。
- 模型翻译使用精简文字请求、较短超时与重复译文缓存。
- 请求进行时保留最新待译文字，结束后继续翻译，不丢掉下一句。
- 临时网络失败不关掉翻译，保留已有字幕并自动退避重试；字幕留足阅读时间。
- 要同时语音聊天与屏幕文字翻译，请配置视觉模型或 LibreTranslate。小智语音通道本身不能同时处理两项请求。视频声音捕获与麦克风聊天需切换使用。

## 自动关闭与语音故障

首页切到后台不再自动暂停常驻语音服务。连接临时断开会重连；语音回答超时会提示原因。若服务只有文字、没有语音包，会提示检查小智后台语音合成设置。

小米手机请在系统设置的 OpenNomi 应用权限中允许悬浮窗，并将电池限制调整为“无限制”，允许后台运行。菜单名称可能随 MIUI 版本不同。系统取消屏幕共享、其他应用抢占麦克风或受保护页面仍可能中断读取。

本版不会后台自行重新获得屏幕共享或麦克风授权。需要开启麦克风和共享时有常驻通知，用户随时可停止。

## 验证范围

构建与测试结果以本次 GitHub Actions 为准；没有用户账号密钥和 Android 真机，不能宣称真实小智账号、蓝牙输出和手机后台保活已验证。

## 持续对话和字幕修复

- NOMI 接收 TTS 开始或语音帧后进入播放状态，不要求一定先收到转写文字；停止会丢弃旧帧。较长回答按实际音轨进度等待，不再被 12 秒总超时截断。
- 点首页的看屏幕、Agent、碎片本时，已启动的原声语音会话继续保留；切换到 AIRI 仍会结束 NOMI，防止两个角色抢麦克风。通知和悬浮面板都有停止入口。
- 翻译采用一个当前请求和最新待译句，断网或临时限流后保留字幕并重试。连接参数改变后清除本机临时缓存，停止共享时取消请求。
- 智谱文字翻译默认使用 glm-4.7-flash，与视觉共用密钥；连接页可填写其他文字模型。请求只有待译文字，不附屏幕图片、控件列表或个人记忆。
- 混合中英文页面优先选取外文行，中文行跳过。无障碍文本更新会直接触发翻译，减少等待下一帧的延迟。
- 字幕阅读时间按译文长度保持 2.5–10 秒；等待期间只保留最新字幕。视频英语部分结果间隔降到约 1.8 秒；视频暂时静音会继续等待。

实际网络延迟、语音服务声音配置、小米后台策略及 Android 13 设备运行仍需真机验证，不承诺固定翻译延迟。
