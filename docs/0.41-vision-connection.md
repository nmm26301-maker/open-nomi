## 手机上的视觉接入

连接页增加 GLM-4.6V-Flash 预设、官方密钥申请入口、加密保存和图片能力测试。官方地址为 `https://open.bigmodel.cn/api/paas/v4`，模型名为 `glm-4.6v-flash`。官方目前将其列为免费模型；注册、密钥、账号权限、限流等规则由服务方管理。

用户需要自行在官方平台登录、创建 API Key，复制后仅粘贴到应用连接页。应用未内置共享密钥，也没有替用户创建账号。官方入口：

- https://bigmodel.cn/usercenter/proj-mgmt/apikeys
- https://docs.bigmodel.cn/cn/guide/models/free/glm-4.6v-flash

保存并测试会发送本机生成的两个随机色块；测试问题不透露实际颜色。返回颜色与图片一致才记为通过。仅接口返回 HTTP 200、仅保存参数、只返回推理过程，都不标记视觉验证通过。验证状态绑定地址、模型和密钥，换配置需要重新测试。

支持基础地址或完整 `/chat/completions` 地址。GLM 使用官方文档所示的 Base64 图片形式并关闭思考以减少空回答和等待；其他兼容服务使用图片 data URL。密钥更换服务主机后不会自动沿用。401/403/404/429 等错误映射成操作提示，不直接显示服务返回的敏感内容。

## 使用断点修复

- 碎片本中的原图可以直接问答，不需要屏幕共享。发送不超过约 1600 像素的推理副本，原图保持不变。
- 看屏幕增加问题输入和直接提问入口。
- 从工作台发起问题或 Agent 后返回目标 App，等待新截图和控件对应，最长等待 15 秒；等待期间可停止共享取消请求。
- Agent 执行成功后的下一轮也等待新截图，解决原来只等 1200ms、截图却每 2400ms 更新的问题。
- 模型输出的点击/填写编号须属于已观察到的对应控件，否则不生成可执行建议。
- 翻译开启后自动回到目标 App；缺少连接时转到连接页。
- 翻译请求失败会暂停翻译并在外部浮条显示原因，避免无反馈地反复请求。点球球可打开工作台检查连接，也可关闭浮条提示。
- 悬浮面板优先显示最新状态，旧回复不再遮住新错误或等待提示。

Agent 仍需要屏幕共享和无障碍服务，每一步仍由用户确认。视频声音识别仍只内置英语模型，是否捕获声音取决于播放应用的系统许可。原声 NOMI / AIRI 保留。

## 已准备的云编译流程

`.github/workflows/opennomi-check.yml` 随源码提交到 nmm26301-maker/open-nomi。编译结果以 Actions 实际记录为准。它按独立 OpenNomi 仓库根目录结构编写，main 更新自动触发，也支持手动触发，执行 Java 回归、AIRI JavaScript 回归、Android 编译、Gradle 单元测试和 lint。若放入现有仓库子目录，需要同步调整工作目录和产物路径。

流程输出的是未签名 APK、检查报告和来自 Android SDK 的签名工具；没有在 workflow 中放入原始签名文件或模型密钥。未签名 APK 不能当作可安装发布包交付，后续必须用原签名签名、校验并确认升级兼容。

OpenNomi 仓库为 https://github.com/nmm26301-maker/open-nomi 。签名文件与模型 API Key 不上传到公开仓库。
