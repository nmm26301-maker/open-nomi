# OpenNomi 0.45：连续操作与功能核对

上一版确实缺少“退出应用”和自动连续任务。本版补齐这两条执行路径，保留 NOMI/AIRI 两个原有入口。

## 语音直接行动

- 分两句说“打开微信”，等回答后说“退出应用”：第二句会回桌面并继续聆听。
- 一句话说“打开微信，然后退出应用”或“打开微信，然后点击搜索，然后输入‘张三’”：可连续执行明确步骤。输入多步任务中的文字请用中文双引号，例如 `输入“张三”`。
- 指令链一次最多十二步，按钮不明确会等待你说第几个；发送、删除、支付等会等待单独的“确认执行”。确认后继续剩余步骤。找不到按钮或执行失败会停止，不会跳过失败继续报完成。
- “退出应用”是离开当前界面回桌面，不会强行终止其它应用后台进程。
- 可说“保存这页”和“记住我正在准备交换申请”。

## 连续 Agent

说“执行任务：打开微信并找到搜索页面”，或在 Agent 页填写目标、点开始连续执行。需要屏幕共享、无障碍和已配置模型；普通明确指令无需视觉模型。

流程参考 Open-AutoGLM 的真实观察与执行循环：最新屏幕与控件 → 下一步 → 实际执行 → 重新观察。每轮带执行记录；一次最多二十步，无效动作、密码页、共享中止、连续无变化会停止或暂停。模型缺少填写资料应询问，不能编造用户信息。

任务进行中也开放小智语音识别，可说“暂停任务”“继续任务”“取消任务”；语音可用性仍取决于网络、小智后台识别和手机麦克风权限。暂停或取消界面按钮也保留。需要确认的动作可用语音或界面确认，页面变化后不能沿用旧控件。

## 小智原声

登记结果里的 websocket.version 决定收发协议，不再硬编码版本三；按官方实现支持版本一原始 Opus、版本二和版本三封包。文字请求带 source=text、mode=manual。首次语音等待延长，只有没有音频时重试一次原声。

系统中文朗读改为设置里的可选回退，默认关闭。失败时保留文字与实际故障说明，恢复聆听；不能保证未配置 TTS 的小智后台凭空产生原声。无需换成系统朗读才能聊天。

## 设计图逐项核对

| 图 | 实际功能 | 范围与限制 |
|---|---|---|
| 首页 | 原有大球球与状态表情，NOMI/AIRI，看屏幕/Agent/碎片本入口 | 保留原角色，未新增五角色；主页球球主要是点击语音，快捷多手势位于外部悬浮球 |
| 屏幕理解 | 共享、离线 OCR、读取页面控件、文字/图片问答、NOMI 播报 | 图片解释需要模型连接；密码、受保护视频和系统禁止截图页面可能不可见 |
| Agent | 明确指令链、连续观察和执行、语音暂停/继续/确认、任务记录 | 不保证所有第三方自绘控件可操作；点击返回成功仅表明控件接受，随后观察页面结果；完成判断仍需模型和页面反馈 |
| 实时翻译 | 屏幕文字与已有字幕翻译、底部浮条、英语视频声音识别、语言模型润色 | 声音捕获取决于播放 App；不是所有语言都能离线识别；OpenNomi 浮条是换行显示，未实现概念图之外的横向滚动 |
| 碎片本 | 原图导入/分享、文字/链接/问答分类、搜索、编辑、标签、AI 概括整理 | 点击 AI 整理才上传所选记录；不会伪造图中示例内容，也不自动把全部相册发给模型 |
| 记忆中心 | 本机记忆、项目/兴趣/生活分类、编辑/删除、语音保存，可选屏幕问答引用 | 普通 NOMI 后台人格/长期记忆仍由其服务管理；本机记忆不会自动注入所有普通语音轮次 |
| 悬浮球 | 外部球球、拖动、保存文字、看屏幕、语音、翻译和历史手势 | 需要悬浮窗授权和共享；不同于对其它应用整屏覆盖 |

以上是功能对应核对，不表示概念图像素还原，也不表示已经在你的手机上验证所有操作。首次 Android 权限、账号服务、MIUI 电池限制和真实第三方 App 仍需手机验证。数据库升级保留原有记录，签名和包名延续旧版，直接覆盖安装。

## 开源来源及实际接入

- https://github.com/78/xiaozhi-esp32 ：采用官方 websocket 协议版本和封包定义；MIT 许可随 APK 附带。
- https://github.com/zai-org/Open-AutoGLM/blob/main/phone_agent/agent.py ：观察、规划、执行、再次观察的连续循环及 do/finish 格式，本机执行层适配 Android 无障碍；Apache-2.0 许可已随包附带。未内置 9B 模型或 ADB Python 运行时。
- https://github.com/xiaoniu/xiaozhi-ai-android ：核对原生 Android 文字输入 source=text 与 Opus 播放流程，调研参考，未复制完整 App。
- Tesseract4Android、Vosk、tessdata_fast、LibreTranslate 的原有实际接入保留，详见 third-party/INTEGRATION.md。

首次授权仍须使用 Android 系统弹窗；授权后普通操作和确认可通过语音完成。不能声称 Android 权限弹窗也已完全免手。
