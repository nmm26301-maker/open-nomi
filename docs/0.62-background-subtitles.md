# 0.62 后台实时翻译与悬浮字幕

## 使用

打开“翻译 → 视频字幕”，选择原声语言并准备模型，允许悬浮窗、录音和屏幕共享。字幕准备好后切换到播放器，或点击“后台显示悬浮字幕”。识别、翻译和浮层由前台服务管理，离开工作台不结束本次字幕。

点悬浮球可隐藏／显示浮层、暂停／继续视频字幕、查看近期译文、调整顶部／中部／底部位置或切换标准／大字。菜单支持滚动，字幕控制优先显示。隐藏浮层不停止识别或清空历史；暂停保留本次共享与已完成译文，浮层标注“已暂停”和上一句，继续时复用当前共享授权。

通知栏显示当前译文，提供“显示字幕”“暂停／继续字幕”“停止共享”。通知使用 PRIVATE 可见性，公开版本不包含原文或译文；锁屏最终展示取决于系统设置。

## 显示处理

译文优先排列，原文与服务提示在其后；没有译文时明确显示等待原声或“识别中”，不把临时识别当作已完成翻译。译文字号独立放大并跟随系统字体缩放。横竖屏变化后重新计算浮层宽度和位置，悬浮球保持在屏内。

字幕窗保留触摸穿透，不占输入焦点；窗口 alpha 从 0.92 调整到 0.78，符合 Android 12 起对不可信穿透浮层的透明度条件。官方依据：https://developer.android.com/reference/android/view/WindowManager.LayoutParams#FLAG_NOT_TOUCHABLE 。这不会绕过播放器的音频捕获限制或系统隐藏浮层的限制。

## 验证范围

新增单元检查覆盖译文优先、等待／部分识别提示、隐藏与暂停保留、停止后不显示、原文开关与服务署名。API 29/33 检查用独立 UID 播放器的真实原声产生中文字幕，确认播放器前台、OpenNomi 后台时的实际浮层视图、屏内范围和系统窗口注册；实际点击穿过字幕窗到达播放器并观察计数变化；执行通知 PendingIntent 隐藏后恢复显示、暂停与继续，并确认共享会话保持；实际操作悬浮菜单调整到顶部，渲染真实浮层视图用于内部布局检查。

没有更换语音识别或翻译模型，不声称准确率、延迟或后台持续时长有实测提升。真机与蓝牙耳机尚未实测；首次模型准备需要联网，播放器须允许系统声音捕获。用户停止共享、强制结束应用或系统终止共享后需要重新开启，不会未经授权自动重建捕获。

包名 com.opennomi.android，版本代码 62，沿用 0.53–0.61 发布签名。

首轮检查尝试按无障碍控件查找不可触摸字幕窗，API 29/33 均未找到而超时；失败 XML 保存在 validation/initial-api-*。后续检查直接检查已附着的真实字幕视图和系统窗口，并实际点击穿透到独立播放器，不为测试改变字幕窗的触摸穿透或安全标记。
