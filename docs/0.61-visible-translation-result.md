# 0.61 译文直接可见

本版包含 0.60 的字幕阅读时长与后台录音停止修复，并补充文字翻译结果的显示处理。

点击“翻译为中文”时清除输入焦点、收起软键盘；真实译文完成后，等待布局更新并请求父滚动区域将结果带入视口。译文标题、文本及 Google 翻译署名位于同一个结果区域。用户不必在输入框中继续拖动寻找结果；视频字幕和近期译文模式不受自动滚动影响。

0.60 在 Android 13 的两次检查中出现文字翻译页面等待超时，尽管原生日志确认模型已返回“你好世界”。复跑还暴露近期译文中的原文可能在当前视口下方。保留两次失败原始 XML 报告；0.61 的文字翻译检查直接等待产品自动展示实际译文，不再用连续滚动掩盖结果未显示；近期译文检查真实滚动到原文再核验。

包名 com.opennomi.android，版本代码 61，沿用 0.53–0.59 的发布签名。识别模型与翻译模型未更换，不声称识别准确率或端到端延迟有实测提升。真机与蓝牙耳机尚未实测。
