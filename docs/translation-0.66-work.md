# 0.66.0 Hy-MT2 连续翻译与离线恢复

本版沿用 0.65 的 Hy-MT2 1.8B Q4_K_M、语音识别与前后台字幕界面，修改连续请求的原生推理和模型准备流程。

- 同一引擎复用完全相同的提示词 token 前缀，删除旧原文尾部和所有旧输出；至少重新计算最后一个输入 token。取消、解码失败或截断后清空复用记录，下次请求重新计算。无法安全截断 KV 时回退完整重算。
- Hy-MT2 仅接收当前识别文本和官方中文翻译指令。上一段识别文字不再拼入提示词，避免旧金额、否定或指令污染当前译文；成功译文缓存也只按当前文本索引。其他翻译引擎未改。
- 已完整下载的临时模型先校验再安装，无需联网。校验失败删除损坏临时文件；取消校验保留文件以便继续。首次模型仍约 1.13 GB，安装包不内置该模型。

构建源提交：`909ac469c06274a4b5ec2c214959bb043fb97f24`。

验证：

- [Android 编译、Release lint、201 项单测与 API 29/33 仪器测试](https://github.com/nmm26301-maker/open-nomi/actions/runs/39965335976)。201 项单测及两套设备各 26 项测试全部通过，完整结果随发布归档。
- [原生真实模型回归](https://github.com/nmm26301-maker/open-nomi/actions/runs/39965336258)：六组冷启动/复用语义检查，以及取消后的缓存清理检查。否定、肯定、方向、金额和日期均检查含义，不要求同义译文逐字一致。测得复用请求 271–571 ms，对照重算 687–911 ms；这是 CI 主机数据，不代表手机延迟。
- 安卓真实模型检查覆盖下载、流式中文、前台与后台可见字幕、断网重载、完整临时文件离线安装、损坏临时文件清理和取消保留；附实际截图与报告。

未发布的背景提示词试验在 [39964603061](https://github.com/nmm26301-maker/open-nomi/actions/runs/39964603061) 暴露模型复述背景、混入旧金额的问题，因此最终版本恢复当前文本的官方提示词。较早严格逐字对照也因“门是关着的/门被关上了”同义措辞差异失败，最终保留两种输出并检查语义；这些试验记录不计作最终通过证据。

还需真实手机测连续视频、长时间内存/发热、蓝牙以及更多口音和语言。有限样例不能证明普遍准确率；语音识别错误仍可能影响翻译。

发布包沿用原签名，包名 `com.opennomi.android`，版本代码 66；131 个分片已从 GitHub 全新克隆回读，恢复出的 APK 与本地签名包逐字节一致，加密备份中的密钥、密码和证书也与签名输入一致。
