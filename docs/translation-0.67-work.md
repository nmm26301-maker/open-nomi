# 0.67.0 Hy-MT2 连续请求与本地模型恢复

构建源提交：`b26879ad2bd34089536a7152c8257f20a16636e5`。

- 已加载引擎的连续请求直接使用已校验的模型路径，跳过每句重复的文件检查、IO 协程切换和准备状态更新。加载与翻译进入同一个串行任务，避免释放操作插在两者之间导致空句柄；模型加载后再次检查协程取消。
- 完整本地模型丢失校验标记时，先在本机重新计算 SHA-256 并恢复标记，断网也能继续使用，不立即重新下载约 1.13 GB 的权重。
- 只有明确的模型哈希不符才删除完整下载临时文件。安装重命名失败保留有效下载，用户腾出存储或修复目录后可重试；取消仍保留文件。

保留 0.66 的原生提示词前缀复用、当前原文专用提示词、Google/在线引擎和后台字幕。本版没有修改原生推理、采样器或语音识别，不据此宣称普遍准确率提升。

验证入口：[Android CI](https://github.com/nmm26301-maker/open-nomi/actions/runs/39991470138)。发布前核对单测、Release lint 和 API 29/33 仪器测试；新增真实模型释放后重译、断网恢复校验标记、模拟安装失败保留有效临时文件的回归检查。
