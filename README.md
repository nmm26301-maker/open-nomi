# OpenNomi Android 0.67.0

[下载 0.67.0 签名安装包](https://github.com/nmm26301-maker/open-nomi/actions/runs/40000043899/artifacts/12521253064)：登录 GitHub 后下载 ZIP，解压安装其中的 APK。

0.67 已加载 Hy-MT2 的连续翻译跳过重复准备；加载和推理串行执行，避免释放时序导致空句柄。完整本地模型可断网恢复校验标记，安装失败保留有效下载。单测、Release lint、API 29/33 实测通过。见 [0.67 优化与回归](docs/translation-0.67-work.md)。

0.66 复用 Hy-MT2 相同提示词前缀，减少连续翻译的重复计算；仅翻译当前识别文本，避免前段内容干扰。修复完整下载文件离线安装、损坏临时文件清理和取消保留。201 项单测、Release lint、API 29/33 各 26 项实测通过，保留后台中文字幕。真机速度与广泛准确率仍待验证。见 [0.66 优化与实测](docs/translation-0.66-work.md)。

0.65 新增 Hy-MT2 1.8B Q4_K_M 本机翻译，可用于视频字幕、文字与画面翻译；原生流式译文同步到后台浮层，暂停或停止后丢弃迟到片段。首次下载约 1.13 GB，支持续传与官方文件导入，之后离线可用。保留 Google 和在线引擎。语音识别不变，手机速度与泛化准确率仍需真机验证。见 [Hy-MT2 接入与实测](docs/hymt2-integration.md)。

0.64 在英语手机翻译的快显模式中，先显示稳定片段的临时中文，并在后台浮层优先展示；完整语句继续按原流程确认，临时译文明确标注可能改写，不进入近期译文。开始收音前预热翻译，正式译文积压或手机处理较慢时减少预览。详见 [0.64 临时译文与验证](docs/translation-0.64-work.md)。

0.63 减少快显模式的字幕展示排队：后续翻译无需等上一条长字幕读完；浮层优先显示较新结果，完整结果保留在最近 20 条译文中。修复部分英语方向省略句的离线错译，保留 0.62 后台浮层和通知控制。识别引擎保持原样，不宣称普遍提高识别准确率。详见 [0.63 修复与实测](docs/translation-0.63-work.md)。

0.62 完善后台实时翻译：切换到播放器或其他应用后继续显示浮层中文字幕；译文优先、可选位置和字号，暂停时保留明确标记；悬浮球与通知支持显示、暂停和继续。详见 [0.62 后台字幕](docs/0.62-background-subtitles.md)。

0.61 文字翻译完成后自动收起键盘并滚动到真实译文，避免结果藏在输入框下方；包含 0.60 的长字幕阅读时长与后台录音停止处理。见 [0.61 译文可见性](docs/0.61-visible-translation-result.md)。0.60 作为验证中间版本保留，Android 13 页面检查失败记录未删除。

0.60 根据译文长度调整字幕停留时间（0.75–4.5 秒），保留字幕队列顺序和近期译文；暂停、重新同步和停止共享时，在后台停止录音并串行释放原生资源，避免界面等待。见 [0.60 阅读时长与暂停响应](docs/0.60-caption-reading-and-stop.md)。

0.59 修复暂停视频字幕后自动转入画面文字翻译的问题，保留共享与近期译文，回看页可直接继续字幕。常用操作和译文前移，运行时默认收起模型设置。见 [0.59 暂停恢复与操作区](docs/0.59-video-pause-and-controls.md)。

0.58 为本机翻译增加相同短句的成功译文复用；显示待完成翻译和待显示字幕数量。字幕落后时可手动重新同步当前声音，跳过积压并保留已完成的近期译文。缓存只在内存中，停止共享后清空。见 [0.58 同步与复用说明](docs/0.58-subtitle-resync.md)。

0.57 优化连续讲话分段：到达时长阈值后先等短停顿，最多额外等待 1.2 秒；字幕积压恢复时按顺序保留短暂阅读时间，避免连续瞬间覆盖。新增本次共享的近期视频译文，保留最近 20 条原文与译文；停止共享后清空。识别提醒依据最不确定的词，避免平均值掩盖低置信度内容。见 [0.57 字幕分段与回看说明](docs/0.57-subtitle-continuity.md)。

0.56 优化视频字幕：新增更快显示／完整语句选择；翻译完成后立即处理下一条，积压时保持顺序合并相邻原文，减少请求次数；降低视频模式下不必要的画面采集和配置解密工作。视频入口放到翻译页首位，并补上悬浮窗授权引导和同一处模型准备进度。详见 [0.56 视频字幕优化](docs/0.56-video-optimization.md)。

0.55 新增无字幕视频的声音翻译：选原声语言，直接识别播放器声音，并显示实时中文字幕与识别原文。新增日语、韩语、法语、德语、俄语、西班牙语模型，英语可选增强模型；修复连续语句被新内容覆盖和字幕阅读等待导致的延迟。首次准备模型后可离线使用。实际功能与限制见 [0.55 视频字幕说明](docs/0.55-video-subtitles.md)。

此前更新重点是连续语音体验：过滤空白识别事件与同一回答期间重复发送的最终识别结果，新增三档说完等待，并将 FishAudio 快速分句播放与麦克风停顿时间分开设置。详情见 [0.53 语音体验与安装说明](docs/0.53-voice-experience.md)。

本次补上无需密钥的手机翻译和直接试译界面，修复未配置视觉服务就无法开启翻译的阻断；继续修复取消开始说话后的重连恢复，并让 FishAudio 在较长短句的逗号到达时立即启动合成，避免等待后续文字。见 [0.54 更新与备份说明](docs/0.54-voice-and-backup.md)。

## 安装身份与签名

0.65.0 沿用 0.53–0.64 的包名和发布签名，可覆盖升级。新版包名为 `com.opennomi.android`，版本代码 67，使用用户保留的新发布签名。它与旧版 `com.opennomi.android.voicetest` 并行安装，不会覆盖或清除旧版。新安装需重新授予权限、绑定设备、填写服务配置；旧版的本机聊天记忆、登录和设置不会自动迁移。不要为了安装新版卸载旧版。

签名私钥和密码只在外部签名步骤使用，源码与 Actions 日志不包含这些凭据。加密备份见本仓库 `backups/signing/new-signing-20261012/`，每版安装包和恢复校验文件归档于 `backups/releases/<版本>/`；恢复凭据单独保存，禁止提交仓库。没有原私钥时不能生成旧包名的覆盖升级包。

# 0.39 基础行为

只保留原来的两个入口：NOMI 原声在线对话、AIRI 网页角色。

- 继续使用 0.29 的 Emotion Ball 形象，球球区域从固定 260dp 改为随屏幕宽度和可用高度调整。
- 深色一体背景、弹性滑动页签、状态淡入、语音电平与按钮按压反馈。
- 表情 SVG 绘制目标约 30fps；进入后台停止表情循环；设置中可减少动效。
- 删除本地模型、五角色、模型导入、角色网关和第三个页签。升级时清理应用私有 offline-models 目录；不删除用户下载目录中的文件。
- 保留安装包 ID、设备标识、绑定信息与 AIRI 登录。首次进入预连接语音服务；麦克风在用户主动开始对话后才开启。
- 手动模式保留 700ms 说完等待；0.39 将起播预缓冲由 180ms 调整为 120ms。
- 收到 TTS 结束后，按顺序等待音频队列和音轨播放结束，取消额外固定 150ms 等待；连续对话恢复录音的额外等待由 200ms 调整为 120ms。
- 音频解码复用缓冲，重连复用网络线程池，呼吸渐变复用绘制资源，减少循环分配。
- 连接中可取消已排队的开始说话；滑动球球不再触发点击；连续对话衔接避免短暂闪回暂停状态。
- 原有设备绑定及签名保持兼容。网络和服务端响应不受本地参数保证，实际体验需真机验证。

## 构建

需要 JDK 17、Gradle 8.7、Android SDK 35 / Build Tools 35.0.0。

```sh
python3 scripts/restore-build-assets.py
python3 scripts/prepare-hymt2.py
gradle :app:assembleRelease :app:testReleaseUnitTest :app:lintRelease
node --test airi-native-voice.test.cjs
```

Hy-MT2 原生构建需要 NDK `27.2.12479018` 和 CMake `3.22.1`；`prepare-hymt2.py` 恢复固定提交的 llama.cpp，运行时模型由手机单独下载。

发布签名由外部 Gradle 属性 OPENNOMI_KEYSTORE、OPENNOMI_STORE_PASSWORD、OPENNOMI_KEY_ALIAS、OPENNOMI_KEY_PASSWORD 提供，源码不含密钥。

## 手机查看编译

打开 [Actions](https://github.com/nmm26301-maker/open-nomi/actions)，查看 OpenNomi Android checks。每次 main 更新自动编译，也可以 Run workflow 手动运行。产物含未签名 APK 的全部分片、签名工具和检查报告；未签名产物不能直接安装。下载并解压 apk-parts 产物后，按 part00、part01 等编号顺序拼接全部分片，不预设固定数量，核对 unsigned-sha256.txt，再用原签名签名。OCR、英语识别和 native AAR 在构建时从官方来源恢复，逐文件核对 SHA-256，安装包仍包含离线数据。

构建记录见仓库 Actions；旧版本验证记录仅适用于对应版本。API Key 在手机里填写；屏幕共享、Agent 与实时翻译的完整体验仍需 Android 13 真机测试。
